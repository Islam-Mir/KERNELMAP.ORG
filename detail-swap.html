SWAP

Sistema di Swap

🔄 MEMORIA SWAP

DESCRIZIONE:

Il sistema di Swap gestisce l'estensione della memoria RAM utilizzando spazio su disco o dispositivi a blocchi compressi, permettendo al sistema operativo di liberare pagine fisiche meno attive e allocarle per processi affamati di risorse.

CONFRONTO:

Come una scrivania di lavoro e un archivio esterno: quando la superficie della scrivania (RAM) è completamente occupata da documenti, i fascicoli meno consultati vengono temporaneamente riposti in un raccoglitore nell'armadio (spazio swap) per fare spazio immediato alle attività correnti.

🔍 Descrizione Tecnica

Il sottosistema di Swap è il meccanismo di virtualizzazione e gestione della memoria che permette al kernel Linux di scaricare pagine di memoria anonima verso aree di swap dedicate. Quando la RAM si riempie, il daemon di background kswapd si attiva per identificare e migrare le pagine inattive verso il dispositivo di swap.

• Page swapping - Spostamento trasparente di pagine di memoria tra la RAM e il supporto di swap

• Swap space management - Gestione di partizioni, file dedicati e strutture di indicizzazione (swap_info_struct)

• Page replacement - Integrazione con l'algoritmo LRU per la selezione delle vittime

• Swap cache - Livello di cache intermedio per evitare scritture ridondanti su disco

• Compressed swap (ZRAM/Zswap) - Compressione in-memory per ridurre l'I/O su disco

• Memory locking - Meccanismi per impedire che pagine critiche vengano swappate (`mlock`)

• Interazione: Collabora strettamente con il memory manager e il sottosistema dei file/dispositivi a blocchi

⚙️ Operazioni Principali

Il sistema di Swap gestisce quattro aspetti fondamentali dell'archiviazione virtuale, ciascuno critico per la stabilità del sistema:

🔄 Page Swapping

• swap_writepage() - Sposta una pagina anonima dalla RAM al dispositivo di swap

• do_swap_page() - Ricarica una pagina dallo spazio di swap alla RAM a seguito di un page fault

• kswapd() - Daemon del kernel che esegue il reclaim asincrono in background

• try_to_free_pages() - Tenta di liberare pagine quando la richiesta di allocazione fallisce

• page_referenced() - Verifica se una pagina è stata recentemente consultata

💾 Swap Space Management

• sys_swapon() - Attiva una partizione o un file di swap nel sistema operativo

• sys_swapoff() - Disattiva un'area di swap migrando i dati residui nella RAM

• swap_duplicate() - Incrementa il contatore dei riferimenti negli slot di swap

• add_swap_extent() - Gestisce la frammentazione e i blocchi contigui dello swap file

• si_swapinfo() - Raccoglie metriche globali sull'utilizzo dello swap

🎯 Page Replacement & Cache

• add_to_swap() - Assegna uno slot di swap a una pagina prima della scrittura

• delete_from_swap_cache() - Rimuove la pagina dalla cache di swap

• shrink_inactive_list() - Scansiona la lista LRU inattiva per identificare le pagine da liberare

• get_swap_page() - Trova e alloca uno slot libero nella mappa di swap

• free_swap_slot() - Rilascia lo slot di swap quando la pagina ritorna in RAM

⚡ Swap Performance & Compressione

• zswap_store() - Intercetta le scritture di swap per comprimerle in RAM

• zram_bvec_write() - Gestisce un disco RAM compresso usato come dispositivo di swap

• swap_cluster_readahead() - Legge blocchi contigui di swap per ottimizzare le prestazioni I/O

• oom_kill_process() - Intervento estremo quando né RAM né swap possono soddisfare le richieste

• blk_start_plug() - Raggruppa le richieste di scrittura su swap per ridurre il overhead

📋 Esempi Pratici

Quando la RAM si satura, ecco cosa succede nel flusso di swap:

🔍 Il Percorso dello Swap-Out e Swap-In

1. La RAM è piena e un processo richiede nuova memoria

2. Il kernel identifica le pagine LRU meno utilizzate tramite kswapd

3. Viene allocato uno slot nello spazio di swap e la pagina viene scritta su disco

4. Se il processo tenta di accedere a quella pagina, si verifica un page fault

5. Il kernel esegue lo swap-in leggendo i dati dal disco e ripristinandoli in RAM

📄 Strutture Dati Chiave

  • swap_info_struct - Descrittore principale di un'area di swap (partizione o file), contiene priorità, dimensioni e flag di stato
  • swap_map - Array di contatori associato a ciascuno slot di swap per tracciarne i riferimenti condivisi
  • swap cache - Struttura (XArray, in passato radix tree) che mantiene temporaneamente in RAM le pagine duplicate nello swap per evitare I/O ridondanti
  • sysinfo - Blocco di informazioni di sistema che include statistiche aggiornate su RAM totale, libera e swap disponibile

💻 Nel Computer: Come Vederlo?

Comandi Linux per esplorare lo swap:

  • swapon --show - Mostra i dispositivi e file di swap attivi con dimensioni e priorità
  • cat /proc/swaps - Elenca i dettagli tecnici delle aree di swap in uso
  • free -h - Visualizza un riepilogo leggibile della RAM e dello spazio di swap
  • vmstat 1 - Monitora in tempo reale le statistiche di swap-in (si) e swap-out (so)
  • zramctl - Mostra lo stato dei dispositivi di swap compressi in RAM (zram)

🎯 Caso Reale: Gestione del Carico Elevato

Quando si avvia un'applicazione pesante su un sistema con poca RAM:

  1. Il kernel riduce la page cache dei file per liberare pagine fisiche
  2. Se non basta, i processi inattivi subiscono lo swap-out delle pagine anonime
  3. I dati vengono scritti sul disco o compressi tramite zswap/zram
  4. Se lo spazio di swap si esaurisce completamente, entra in azione l'OOM (Out-Of-Memory) killer

💾 Tipi di Swap

  • Partizione di Swap - Una partizione di disco dedicata, la forma più classica ed efficiente
  • File di Swap - Un normale file all'interno di un filesystem, flessibile e facile da ridimensionare
  • ZRAM - Dispositivo di swap compresso direttamente in RAM, ideale per dispositivi con risorse limitate
  • Zswap - Una cache di compressione anteriore che comprime le pagine prima di scriverle sul disco di swap
  • Swap di rete - Utilizzato in ambienti diskless tramite protocolli di rete avanzati

✨ Caratteristiche

  • Prioritizzazione - Possibilità di configurare priorità multiple per l'uso dei dispositivi di swap
  • Compressione Dinamica - Riduzione drastica dell'I/O su disco tramite zswap e zram
  • Prevenzione del Thrashing - Meccanismi di tuning (swappiness) per bilanciare file cache e swap
  • Protezione dei Dati - Crittografia opzionale dello swap space per motivi di sicurezza
  • Hotplugging - Attivazione e disattivazione a caldo di file e partizioni di swap

🔗 Interazioni Chiave

Il sottosistema di Swap interagisce profondamente con diversi componenti del kernel:

🧠 Memory Management Subsystem

• Page allocator - Richiede interventi di swap quando le soglie di watermark della RAM sono critiche

• LRU lists - Strutture di gestione delle pagine attive e inattive utilizzate per selezionare le vittime dello swap

• Page fault handler - Intercetta l'accesso a pagine swappate e scatena le operazioni di caricamento

💽 Block Device & Storage Layer

• Block layer - Riceve le richieste di I/O per la lettura e scrittura dei blocchi di swap

• IO scheduler - Ottimizza la coda delle richieste di scrittura per minimizzare il tempo di ricerca del disco

⚡ Compression & Cryptography Engines

• Crypto API - Fornisce algoritmi di compressione rapida (es. LZO, LZ4, ZSTD) usati da zswap/zram

🛡️ System Protection

• OOM Killer - Sottosistema di ultima istanza che termina i processi quando la memoria virtuale è totalmente esaurita

🛠️ API Principali

Queste sono le interfacce di sistema e le chiamate interne utilizzate dal kernel e dai programmi di servizio:

📂 Gestione Attivazione Swap

int swapon(const char *path, int swapflags);
Attiva il file o la partizione specificata come area di swap per il kernel.

int swapoff(const char *path);
Disattiva l'area di swap indicata, svuotandone i contenuti e riallocandoli in RAM.

🔒 Blocco della Memoria

int mlock(const void *addr, size_t len);
Impedisce alle pagine specificate di essere spostate nello spazio di swap (rimangono bloccate in RAM).

int munlock(const void *addr, size_t len);
Rilascia il blocco della memoria, rendendo nuovamente le pagine idonee allo swap.

⚙️ Parametri di Tuning (sysctl)

vm.swappiness
Controlla la tendenza del kernel a swappare le pagine anonime rispetto al rilascio della page cache (valori da 0 a 200 dal kernel 5.8; default 60).

vm.vfs_cache_pressure
Determina la tendenza del kernel a liberare la memoria cache di dentry e inode rispetto alla memoria dei processi.

🔄 Cosa succede dietro le quinte:

  1. 1. Reclaim: Il kernel individua le pagine meno usate tramite la lista LRU
  2. 2. Allocazione Swap: Viene scelto uno slot libero tramite la `swap_map`
  3. 3. Scrittura: La pagina viene compressa (se zswap è attivo) o scritta direttamente su disco
  4. 4. Page Fault: Se il processo richiede nuovamente i dati, si genera un fault
  5. 5. Swap-In: Il kernel ricarica la pagina in RAM e libera lo slot di swap
🎯 Risultato: Il sistema mantiene l'esecuzione fluida dei programmi attivi spostando temporaneamente i dati inattivi sullo spazio di swap.

🎯 Concetti Chiave da Ricordare

⚖️

Swappiness

Parametro di tuning che bilancia il compromesso tra il rilascio della page cache e lo spostamento delle pagine anonime su swap.

🌪️

Thrashing

Condizione critica di rallentamento estremo in cui il sistema passa più tempo a fare swap-in/swap-out che a eseguire codice utile.

📦

Zswap / Zram

Tecnologie di compressione in-memory che riducono drasticamente l'I/O su disco accelerando le operazioni di swap.

🚨

OOM Killer

Meccanismo di emergenza del kernel che termina i processi quando memoria RAM e spazio di swap sono completamente esauriti.
