NETWORK STORAGE

Storage di rete

💾 STORAGE RETE

DESCRIZIONE:

Il Network Storage subsystem gestisce l'accesso allo storage di rete nel kernel Linux, implementando protocolli come NFS, CIFS/SMB, iSCSI e altri sistemi di storage distribuito. Coordina la comunicazione tra client e server di storage attraverso la rete.

CONFRONTO:

Immagina il Network Storage come un magazzino remoto: invece di avere gli scatoloni (dati) nel tuo garage, li tieni in un deposito esterno accessibile via strada (rete). Puoi andare a prendere quello che ti serve quando vuoi, ma devi considerare il traffico e i tempi di consegna.

🔍 Descrizione Tecnica

Il Network Storage subsystem è responsabile dell'implementazione dei protocolli di rete per l'accesso ai dispositivi di storage remoti. Include client e server per filesystem distribuiti, block storage over IP, e meccanismi di caching per ottimizzare le prestazioni.

• Protocol Implementation - Implementazione protocolli NFS, CIFS, iSCSI

• Remote File Access - Accesso trasparente a file su server remoti

• Block Storage over IP - Trasmissione blocchi dati via rete

• Interfaccia principale per storage distribuito

⚙️ Operazioni Principali del Network Storage

Il Network Storage esegue operazioni critiche per l'accesso allo storage remoto:

⚙️ NFS Operations

• nfs_getattr() - Ottiene attributi file dal server NFS

• nfs_lookup() - Risolve pathname su server remoto

• nfs_readpage() - Legge pagine da file NFS

• nfs_writepage() - Scrive pagine su file NFS

⚙️ CIFS/SMB Operations

• cifs_reconnect() - Riconnette sessioni SMB interrotte

• cifs_readv() - Lettura vettoriale da share SMB

• cifs_writev() - Scrittura vettoriale su share SMB

• cifs_mkdir() - Crea directory su share remoto

⚙️ iSCSI Operations

• iscsi_queuecommand() - Invia comandi SCSI via rete

• iscsi_session_recovery() - Recupero sessioni iSCSI

• iscsi_host_alloc() - Alloca host iSCSI

• iscsi_conn_bind() - Associa connessioni iSCSI

⚙️ Caching e Performance

• nfs_fscache_enable() - Abilita cache FSC per NFS

• cifs_readdata_to_iov() - Ottimizza lettura dati SMB

• iscsi_tcp_segment_done() - Gestisce segmentazione TCP

• nfs_pageio_init() - Inizializza I/O pagine asincrono

📋 Esempi Pratici del Network Storage

Il Network Storage opera in ogni accesso a file remoti:

🔍 Montaggio NFS

1. Client invia richiesta MOUNT al server NFS

2. Server risponde con handle del filesystem

3. Client crea superblock NFS e dentry cache

4. File remoti diventano accessibili localmente

📄 Strutture Dati Chiave

  • struct nfs_server - Gestisce connessione a server NFS, include indirizzo, versione protocollo, mount options
  • struct cifs_sb_info - Informazioni superblock per share CIFS, contiene credenziali e opzioni mount
  • struct iscsi_session - Sessione iSCSI con parametri connessione, autenticazione, timeout
  • struct nfs_inode - Estende inode standard con attributi NFS (filehandle, cache timeout)
  • struct cifsFileInfo - Informazioni file CIFS aperto, include handle server e lock status

💻 Comandi Linux Essenziali

  • $ mount -t nfs server:/share /mnt/nfs - Monta share NFS
  • $ mount -t cifs //server/share /mnt/smb -o username=user - Monta share SMB/CIFS
  • $ showmount -e server - Mostra export NFS disponibili
  • $ smbclient -L server - Lista share SMB disponibili
  • $ iscsiadm -m discovery -t sendtargets -p server - Scopre target iSCSI

🎯 Caso Reale: Accesso File Remoto

Quando fai $ cat /mnt/nfs/remotefile.txt:

  1. VFS inoltra richiesta a NFS client
  2. NFS client invia RPC GETATTR al server
  3. Server risponde con attributi file
  4. NFS client richiede READ con offset
  5. Dati trasferiti via rete e cachati localmente

💾 Supporto e Compatibilità Network Storage

  • NFSv4.2 - Network File System con supporto avanzato
  • CIFS/SMB3 - Protocollo Microsoft con sicurezza avanzata
  • iSCSI - Block storage over IP con estensioni
  • Ceph/RADOS - Storage distribuito scalabile
  • GlusterFS - Filesystem distribuito
  • pNFS - NFS parallelo per cluster
  • FSCache - Framework caching per storage remoto
  • 9P - Protocollo Plan 9 per virtualizzazione

✨ Caratteristiche Avanzate

  • Transparent Caching - Cache locale trasparente per prestazioni
  • Failover automatico - Ricovero trasparente su failure
  • Load Balancing - Distribuzione carico su multiple connessioni
  • Security Integration - Integrazione con Kerberos e autenticazione

🔗 Interazioni Chiave del Network Storage

Il Network Storage collabora con molti componenti del kernel:

💾 Virtual File System

• VFS Integration - Registra filesystem di rete come NFS, CIFS

• Dentry Cache - Cache nomi file remoti per prestazioni

🌐 Network Stack

• RPC Layer - Remote Procedure Calls per NFS

• TCP/UDP - Trasporto dati affidabile/non-affidabile

🧠 Memory Management

• Page Cache - Cache pagine per file remoti

• FSCache - Framework caching avanzato

🔒 Security Framework

• Kerberos - Autenticazione sicura per NFS/CIFS

• Access Control - Controllo permessi su file remoti

🛠️ API del Network Storage

Le principali funzioni per lavorare con lo storage di rete:

🔗 NFS Client API

struct nfs_server *nfs_create_server(struct nfs_mount_info *mount_info);
Crea connessione a server NFS con parametri di mount.

int nfs_getattr(struct vfsmount *mnt, struct dentry *dentry, struct kstat *stat);
Ottiene attributi file dal server NFS remoto.

int nfs_open(struct inode *inode, struct file *filp);
Apre file NFS remoto e stabilisce connessione dati.

ssize_t nfs_file_read(struct file *filp, char __user *buf, size_t count, loff_t *pos);
Legge dati da file NFS con caching intelligente.

💼 CIFS/SMB API

struct cifs_sb_info *cifs_get_sb_info(struct super_block *sb);
Ottiene informazioni superblock per share CIFS.

int cifs_mount(struct cifs_sb_info *cifs_sb, struct smb_vol *vol);
Monta share SMB con autenticazione e opzioni.

int cifs_reconnect(struct TCP_Server_Info *server);
Riconnette sessioni SMB interrotte automaticamente.

💽 iSCSI API

struct iscsi_session *iscsi_create_session(struct Scsi_Host *shost, struct iscsi_transport *transport, int initial_cmdsn);
Crea sessione iSCSI per accesso block storage remoto.

int iscsi_queuecommand(struct Scsi_Host *shost, struct scsi_cmnd *cmd);
Invia comandi SCSI incapsulati via rete iSCSI.

int iscsi_conn_bind(struct iscsi_session *session, struct iscsi_conn *conn, int is_leading);
Associa connessione TCP a sessione iSCSI.

🔍 Esempi di Utilizzo Pratico

Come utilizzare le API dello storage di rete:

  1. mount -t nfs server:/share /mnt - Monta filesystem NFS
  2. mount -t cifs //server/share /mnt - Monta share SMB
  3. iscsiadm -m node -l - Connette target iSCSI
  4. showmount -e server - Esplora export NFS

Queste API forniscono accesso trasparente allo storage remoto
